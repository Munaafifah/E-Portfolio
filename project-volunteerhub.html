VolunteerHub: uniting organizations and volunteers around activities that actually fill up correctly.

A volunteer activity registration system built on a layered Spring Boot API and a React frontend, designed around one core problem: keeping registrations accurate when capacity, deadlines, and duplicate sign-ups are all in play.

View Live Demo

The problem

What was missing

  • No simple way for organizations to post activities or for volunteers to browse and join them.
  • Nothing stopped duplicate sign-ups or activities silently overfilling past capacity.
  • Admins had no clear view of who had actually registered.

Scope — two roles

  • Volunteer: browse, search/filter, register, cancel, view own registrations.
  • Admin: full CRUD on activities, view all registrations, view reports.

Why a layered backend

  • Controllers only handle HTTP, services only handle rules, repositories only handle data.
  • Each layer can be tested and fixed in isolation.
  • Matches standard Spring Boot convention — easy for another developer to pick up.

Business rules

No duplicate registration

A user can't register twice for the same activity.

Deadline check

Registration is blocked once the registration deadline has passed.

Capacity check

No further registrations once an activity hits capacity.

Save & increment

Once checks pass, the registration saves and the activity's count goes up by one.
