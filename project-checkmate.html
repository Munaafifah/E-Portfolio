Checkmate.AI: turning a resume and a job description into the interview you should actually prepare for.

An interview-prep tool that pairs an embedding-based ML scoring service with LLM generation. It measures how well a resume fits a target role, surfaces the gaps, and generates tailored questions — technical questions on weak areas, behavioral questions on strengths.

🚧 Live Demo — Coming Soon

The problem

What was missing

  • Generic interview-question lists don't reflect the specific gaps between a candidate's resume and the role they're applying for.
  • Asking an LLM alone to "rate my fit" produces a guess, not a measurement — the score can change from one run to the next.
  • Job seekers need to know which requirements they're weak on, not just a single number.

What Checkmate.AI does

  • Accepts a resume as a PDF upload or pasted text, alongside a target job description.
  • Computes a 0–100 fit score and lists matched and missing requirements, each backed by the closest line in the resume.
  • Generates 5 technical questions on the gap areas and 5 behavioral questions on the strengths.
  • Grounds the LLM in the computed score, so the summary and questions follow real analysis instead of the model's own guess.

Why this shape

  • The ML scoring runs as a separate Python service, where the embedding ecosystem lives, while Spring Boot stays the single entry point for the frontend.
  • The backend scores first, then passes the result into the LLM prompt as ground truth — the LLM explains and generates, it doesn't decide the score.
  • If the ML service is unreachable, the backend degrades gracefully to LLM-only analysis instead of failing the request.
  • The LLM is asked for strict JSON output, with an automatic retry if the response can't be parsed.

How the scoring works

Split into lines

Resumes and job descriptions are mostly bullet points, so both are split by line. Each JD line becomes a requirement; each resume line becomes potential evidence.

Embed & compare

Every line is embedded with the all-MiniLM-L6-v2 model, and each requirement is compared against every resume line using cosine similarity.

Match or gap

Requirements whose best match clears the threshold are marked as matched; the rest become gaps. The overall score is the average best-match similarity, scaled to 0–100.

Grounded generation

The score, matched requirements, and gaps are sent to the LLM, which writes the fit summary and targets its questions at those exact areas.

What's next

Mock interview mode

  • The LLM plays the interviewer, asks a question, and gives feedback on the user's answer.
  • Support for both typed and spoken answers.

Progress over time

  • Deploy the full stack so the tool can be tried live.
